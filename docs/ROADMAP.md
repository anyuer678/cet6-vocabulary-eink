## 一、设计语言

### 1.1 普通版 & EXE — 透明简洁风
- 卡片：`rgba(255,255,255,0.4)` 纯透明背景，无模糊效果
- 按钮：纯色填充，无渐变无阴影
- 背景：白色渐变，可选紫/蓝/绿/橙色调微透
- 色板：紫色主色 `#6366F1`，中性灰背景 `#ffffff`
- 导航栏：半透明 `rgba(255,255,255,0.92)`
- 状态栏：跟随主题色调变化

### 1.2 墨水屏版 — 纯线条风
- 所有卡片/模块：透明背景 + 黑色边框线
- 按钮：描边为主，仅"主要操作"填充黑色
- 无阴影、无动画、无渐变、无模糊、无主题色
- 字号放大，提升可读性

### 1.3 通用原则
- 不使用表情符号（发音按钮 🔊 除外）
- 按钮文字不换行（`white-space:nowrap`）
- 所有显示的模块都必须可交互

## 四、技术架构

### 4.1 前端结构（已模块化）
```
www/
├── index.html          # 主入口（~940行）
├── css/style.css       # 所有样式
├── js/app.js           # 所有逻辑
└── phon/               # 音素数据

www-eink/
├── index.html          # 墨水屏入口（~1130行）
├── css/style.css       # 墨水屏样式
├── js/app.js           # 墨水屏逻辑
└── phon/               # 音素数据
```

### 4.2 技术栈
- 前端：原生 HTML/CSS/JS（无框架）
- 移动端：Capacitor v6
- 构建：Gradle 8.2.1 + AGP 8.2.0
- TTS：eSpeak-ng（JNI桥接）
- 存储：localStorage

### 4.3 构建规范
- 版本号：`1.0.YYYYMMDD.NNN`
- 构建脚本：`.\scripts\build.ps1 all "更新说明"`
- 备份：`dist/backup/YYYYMMDD/NNN/`
- 正式版：`dist/releases/{版本号}/`

### 4.4 目录结构
```
word/
├── www/                    # 普通版源码
├── www-eink/               # 墨水屏版源码
├── android/                # 普通版Android工程
├── android-eink/           # 墨水屏版Android工程
├── electron/               # Windows Electron工程
├── scripts/build.ps1       # 构建脚本
├── dist/                   # APK输出
│   ├── backup/             # 每日备份
│   └── releases/           # 正式版本
├── ROADMAP.md              # 本文件
└── RELEASES.md             # 正式版本记录
```

## 七、开发规范

### 7.1 代码同步
- `www/` 和 `www-eink/` 的通用功能必须同步
- 墨水屏专属：按键处理、eink CSS、禁用动画
- 普通版专属：滑动手势、长按菜单、动画效果

### 7.2 构建流程
1. 修改代码后检查JS语法：`node --check`
2. 检查div标签配对
3. 使用构建脚本：`.\scripts\build.ps1 all "说明"`
4. 验证两个APK都能正常运行

### 7.3 版本管理
- 每次构建更新版本号（日期+序号）
- 所有历史版本保留不覆盖
- 正式版本存放在 `dist/releases/`
